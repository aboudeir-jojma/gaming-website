🚀 Learn Drawing の遊び方

ミニアーティストになりたくない？Learn Drawing はとっても簡単で、信じられないほど楽しいんだ！以下の簡単な手順に従ってね：

1. 絵を選ぼう

好きなスケッチをタップしてみて—遊び心満載の子猫、迫力満点のドラゴン、あるいはきらきら光る宇宙船など。各画像は子供たちのために特別にデザインされているから、いつでもワクワクするものが見つかるよ。

2. 輪郭をなぞろう

指やマウスを使って点線に沿ってなぞってみて。ゆっくり動かして、目の前に形が現れるのを見てね。なぞることで、自分一人で曲線や角、クールなディテールを描くことを学ぶよ。

3. ツールを選ぼう

カラフルなツールボックスに飛び込んで、ペイントブラシ、クレヨン、またはマーカーを選ぼう。ちょっとずれてしまった線を消したい？消しゴムがすぐそこにあるよ。新しいスタイルを試すためにいつでもツールを切り替えよう。

4. マスターピースを色付けしよう

色のスウォッチをタップして、描いている絵の異なる部分を色付けしてみて。明るい赤、晴れた黄色、深い青—組み合わせて、絵を引き立たせよう！各完璧な色埋めで星をゲット！

5. 星を集めてもっとアンロックしよう

作品を完成させるたびに、星を集めて新しくて素敵な画像をアンロックできるよ。描けば描くほど、もっとクリエイティブなチャレンジが待っていて、毎日描くスキルを磨くことができるんだ！

🔒 コントロール

君の鉛筆ヒーローを導くのは簡単で楽しいよ！左（←）と右（→）の矢印をタップしてキャンバスを移動させて、上（↑）の矢印やスペースバーを使ってどんな障害物を越えよう！自分の形を描きたい？ただマウスをクリックしてドラッグするだけだよ。何かを消したいなら、マウスを右クリックしてみて。やり直したいなら、Rを押してリセットしてね。Learn Drawing の一番いいところは、ブラウザで直接動作するから、ダウンロードも待ってもいらないことなんだ！
